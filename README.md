# One_Person_Company_AI_Agents_Workshop_2026

**A 12-Day Learning Journey into AI Agents | Aditya University – Department of Technical Training (DoTT)**

## 📌 About This Repository

This repository documents my 12-day learning journey through the **AI Agents Training Program** organized by the Department of Technical Training (DoTT), Aditya University.

The program focuses on understanding Large Language Models (LLMs), building AI agents, working with tools and integrations, designing agentic workflows, and developing practical AI applications.

I will use this repository to maintain my learning notes, technical concepts, Python implementations, practical tasks, assignments, experiments, and project work.

## 🎯 Learning Objectives

- Understand how Large Language Models (LLMs) work.
- Learn prompt engineering and structured JSON outputs.
- Explore Python fundamentals for AI development.
- Build AI agents using LLM APIs.
- Understand tools, Pydantic, and external integrations.
- Learn memory mechanisms and Retrieval-Augmented Generation (RAG).
- Build agentic workflows using LangGraph.
- Understand agent hand-offs and human approval.
- Explore AI workforce architecture with supervisors.
- Integrate AI agents with Telegram, Google Sheets, and Gmail.
- Develop reliable, safe, and cost-effective AI agents.
- Test, evaluate, and demonstrate practical AI applications.
